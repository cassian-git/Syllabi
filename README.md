# Syllabi

> **Turn hectic syllabi into simple concepts and active recall flashcards.**  
> An open-source, local-first study platform built to help students conquer dense course outlines without cramming.



## Features:

- **Syllabus Parsing:** Dump course outlines, module topics, or raw text to extract key learning points.

- **ELI5 Concept Simplifier:** Complex academic jargon broken down into simple, intuitive summaries.

- **Active Recall & Spaced Repetition:** Flashcard review engine powered by the SuperMemo-2 (SM-2) algorithm.

- **Local-First & Offline Ready:** Everything is stored directly in your browser's local storage—zero login or cloud server required.

- **Mobile & Desktop Optimized:** Clean, lightweight web interface that runs smoothly anywhere.
